# 📸 Instagram Clone Website

A simple **Instagram-inspired clone website** that I built while learning and practicing **Git and GitHub**.

The project recreates some of the core visual elements of Instagram, giving me a hands-on way to practice working with files, commits, branches, repositories, and version control.

## 🚀 About the Project

This project was created primarily as a **learning project**. While building it, I wanted to understand how Git works in a real project instead of only learning commands theoretically.

The website is inspired by Instagram's interface and focuses on creating a familiar social-media-style layout.

### 🎯 Main Goals

* Learn and practice **Git fundamentals**
* Understand how repositories work
* Practice making and tracking changes with commits
* Learn how to work with project files using Git
* Get comfortable using **GitHub**
* Build a small project while learning web development
* Understand how version control fits into a development workflow

## 🛠️ Technologies Used

* **HTML** for the structure of the website
* **CSS** for styling and layout
* **Git** for version control
* **GitHub** for storing and managing the repository

## 📚 What I Learned

While working on this project, I practiced several important Git concepts, including:

* Initializing a Git repository
* Checking repository status
* Tracking files
* Creating commits
* Writing commit messages
* Understanding the staging area
* Viewing changes
* Working with GitHub repositories
* Understanding how Git tracks changes in a project
* Managing files and folders inside a repository

This project helped me understand that Git isn't just about saving files. It provides a proper history of how a project evolves over time.
